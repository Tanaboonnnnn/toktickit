## Current reflection

PR #27 review feedback identified unsafe ambiguous-upload retry gating, incomplete UI/API evidence, missing request-level file-cleanup assertions, and inconsistent Attachment button styling. Later Issue #28 work added the remaining API/UI/style/E2E/responsive evidence. During browser hardening, repeated failures were traced to a stale Vite process caused by the original Windows test harness rather than to the product. The harness was changed to directly own the API/Vite child processes, a second Playwright lifecycle was removed, and ambiguous Ticket/Attachment response-loss tests were rebuilt so the backend completes before the browser loses the response. Live GitHub evidence now confirms that PR #29 received Changes Requested, an author response, a final APPROVED re-review, and merge into `lab2-staging`. Fresh command results remain local evidence in `tests.md`; no CI result is claimed.

AI was used for repository inspection, implementation planning, contract traceability, schema/API/client implementation assistance, test design, verification, audit, and evidence drafting. The output remains subject to student ownership: compare the documents against the Lab 2 handout, review all design decisions, and record only real implementation, test, build, migration, and review results. No CI link or future test outcome has been invented; peer-review and merge statements are limited to the live GitHub artifacts cited in `reviewer.md`.

## Human ownership and decisions

The merged `docs/lab-02` contract remained the source of truth. Human decisions recorded during this work were:

- Development Requester is a temporary testing context, not authentication.
- During the early Issue #14 increment, API-02 was deferred instead of inventing a fake requester-scoped endpoint; it was implemented in the later Ticket API increment.
- Ticket and Attachment models were allowed only as the schema foundation required by the approved single additive Lab 2 migration; later Ticket/Attachment product behavior remains out of Issue #14.
- No Redux, Zustand, Axios, or React Router dependency was added.
- Test-database isolation was required before database TDD and verification.
- Audit findings outside the early Issue #14 scope were intentionally deferred to their approved later Lab 2 increments.
- Only tests that existed, executed, and passed were promoted from Planned to Pass.

AI assistance did not own these engineering decisions, and this record does not claim that the human manually authored code that was generated with AI assistance.
